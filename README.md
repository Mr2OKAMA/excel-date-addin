# excel-date-addin

設定した数字と `yymmdd`（今日の日付）を連結し、選択中のセルに**文字列**として出力する Excel アドインです。

**Windows デスクトップ Excel では、以下の XLAM 版を利用できます。Office アドインカタログ・SharePoint・`manifest.xml` の登録・Web サーバーは不要です。** 既存の Office.js 版は Web 版などのために残しています。

例: 設定値が `1234`、日付が 2026-10-17 の場合 → `1234261017`

## デスクトップ用 XLAM 版

### 配布物と前提

- VBA ソースは [`vba/DateNumberOutput.bas`](vba/DateNumberOutput.bas) です。標準モジュール1個だけで動作し、UserForm・外部ライブラリ・追加の参照設定は不要です。
- **このリポジトリに `DateNumberOutput.xlam` バイナリは含まれていません。** この開発環境には Windows デスクトップ Excel がなく、XLAM の作成・VBA のコンパイル・実機動作確認は行っていません。以下の手順で利用者または配布担当者が作成してください。拡張子を変更するだけでは XLAM にはなりません。
- 対象は VBA が利用できる Windows デスクトップ Excel です（32 / 64 ビット共通）。Excel for the web では VBA / XLAM は動作しません。Mac はこの手順の対象外です。
- 組織が VBA マクロを禁止している場合は、カタログが不要でも利用できません。管理者に確認してください。

### 1. VBA ソースから `DateNumberOutput.xlam` を作成

1. Windows デスクトップ Excel で**新しい空白のブック**を作成します。業務用ブックにコードを追加しないでください。
2. `Alt + F11` で Visual Basic Editor（VBE）を開きます。プロジェクト エクスプローラー（`Ctrl + R`）で**新しいブックの VBAProject** を選択します。
3. **挿入 → 標準モジュール**を選び、プロパティ ウィンドウ（`F4`）の `(オブジェクト名)` を `DateNumberOutput` にします。`ThisWorkbook` や `Sheet1` ではなく、追加した標準モジュールにコードを入れます。
4. ダウンロードした `vba/DateNumberOutput.bas` を **UTF-8 対応のテキストエディター**で開き、先頭の `Attribute VB_Name = "DateNumberOutput"` **だけを除いて**、`Option Explicit` から末尾までをモジュールに貼り付けます。日本語が正しく表示されることを確認してください。
   - `.bas` はレビュー用に UTF-8 で管理しています。VBE の「ファイルのインポート」は Windows のコードページで読み込むため、そのままインポートすると日本語が文字化けする場合があります。上記のコピー＆貼り付けを推奨します。日本語 Windows でインポートする場合は、別のコピーを Shift-JIS（CP932）で保存してから、**モジュールの手動追加の代わりに**インポートしてください（この場合は `Attribute` 行を残します）。
5. VBE の **デバッグ → VBAProject のコンパイル**を実行し、エラーがないことを確認します。ブレークモードの場合はリセットしてから実行してください。
6. `Alt + F11` で Excel に戻り、**ファイル → 名前を付けて保存 → 参照**で、ファイルの種類を **Excel アドイン（`*.xlam`）**にし、ファイル名を **`DateNumberOutput.xlam`** として保存します。安定したローカルフォルダー（例：`%APPDATA%\Microsoft\AddIns`）を使用してください。
7. Excel を完全に終了します。作成した `.xlam` を配布できますが、利用者の設定値はファイルに含まれません。ソースを変更した際は再コンパイル・再保存・再検証し、署名する場合は最後に行います。

### 2. Excel にインストール

1. 作成した（または配布された）`DateNumberOutput.xlam` をローカルの固定フォルダーに置きます。インストール後は移動・削除しないでください。
2. Excel で **ファイル → オプション → アドイン**を開き、下部の **管理：Excel アドイン → 設定**を選択します。**Office アドイン／信頼できるアドインカタログの画面ではありません。**
3. **参照**から `DateNumberOutput.xlam` を選び、一覧の該当アドインにチェックを付けて **OK** を押します。
4. 次のセキュリティ上の注意に従ってマクロを利用できる状態にし、通常の作業用ブックを開きます。XLAM 自体は編集用ワークシートとして表示されません。
5. 解除する場合は同じ **Excel アドイン**の一覧でチェックを外します。更新時は Excel を完全に終了してからファイルを差し替えます。

### マクロのセキュリティ・署名

- ソースと配布元を確認し、信頼できるファイルだけを利用してください。**「すべてのマクロを有効にする」設定は不要であり、推奨しません。** VBA プロジェクト オブジェクトモデルへのアクセス許可も不要です。
- インターネットから取得した `.xlam` は Windows によりブロックされる場合があります。Excel を閉じ、信頼性を確認したファイルの **プロパティ → 全般 → 許可する（ブロックの解除）→ 適用**を行ってから読み込みます。この項目は表示されない場合もあります。組織ポリシーによるブロックは解除せず管理者に相談してください。
- 必要なら管理者の承認のもと、専用の管理されたフォルダーだけを **トラスト センター → 信頼できる場所**に登録してください。ダウンロードフォルダー全体などを信頼しないでください。
- 組織配布では信頼された発行元による VBA 署名を推奨します。配布担当者が VBE の **ツール → デジタル署名**で適切なコード署名証明書を選択して保存し、利用側は組織の証明書／発行元の信頼ポリシーに従います。コード変更は署名を無効にするため再署名が必要です。自己署名は自分の PC での検証用であり、他の PC が自動的に信頼するものではありません。

### 3. 使い方

XLAM 版は Office.js 版のタスクペインやホームタブのボタンを追加しません。次のマクロで操作します。

1. 作業用ブックを開き、`Alt + F8` の **マクロ名**欄に **`'DateNumberOutput.xlam'!ConfigurePrefix`** と直接入力して **実行**します。アドインのマクロは一覧に表示されない場合もありますが、名前を指定して実行できます。
2. 「日付付き番号出力 - 設定を保存」で半角数字（`0`〜`9`）を入力し **OK** を押します。「保存しました」と表示されます。先頭の `0` は保持されます。キャンセルや不正な入力では以前の設定を変更しません。
3. 出力先のセルを選択し、`Alt + F8` で **`'DateNumberOutput.xlam'!OutputDateNumber`** を直接指定して実行します。アクティブな1セルの書式を文字列（`@`）にしてから、保存した設定値と PC の今日の日付 `yymmdd` を出力します。**既存の内容は上書きされ、通常の「元に戻す」では戻せません。**
4. 設定変更は `ConfigurePrefix` を再実行します。設定は `SaveSetting` / `GetSetting` により Windows ユーザーごとの `HKEY_CURRENT_USER\Software\VB and VBA Program Settings\DateNumberOutput\Settings` の `Prefix` に保存され、Excel の再起動後や別ブックでも共通です。Office.js の設定とは同期しません。

例：設定値 `0012`、PC の日付が 2026-10-17 の場合、出力は **`0012261017`**（文字列）です。未設定時（または空文字を保存した場合）は既存版と同様、日付6桁だけを出力します。符号・小数点・空白・全角数字は受け付けません。設定入力には Excel 標準の入力ダイアログを使用するため、長大な設定値には向きません。

### 実機での確認（作成・更新時）

自動テスト基盤はありません。作成した XLAM を Windows Excel で読み込み、空のテスト用ブックで次を確認してください。

- `0012` を保存し、出力が `0012` + 実行日の `yymmdd` になる。セルの表示形式が「文字列」で、先頭のゼロが残る。
- Excel を終了・再起動しても設定が残り、別ブックにも同じ設定で出力される。
- `12a`、`１２`、`-1`、`1.2`、空白入りの入力を拒否し、保存済み設定が変わらない。キャンセルでも変わらない。
- 複数セルを選択して実行してもアクティブな1セルだけが変わる。
- 未設定の Windows ユーザーでは日付6桁だけが出力される。
- 保護されたロック済みセルやグラフシートではエラーを通知し、正常なセルに戻すと出力できる。

## 既存の Office.js 版

### 機能

- タスクペインで任意の数字を保存(`Office.context.roamingSettings`)
- 「出力」ボタンでアクティブセルに `設定値 + yymmdd` を出力
- 区切り文字なし、書式は文字列(`@`)で先頭の0も保持

## ファイル構成

| ファイル | 説明 |
|---|---|
| `manifest.xml` | アドインのマニフェスト |
| `taskpane.html` | タスクペインのUI |
| `taskpane.js` | 設定保存と出力のロジック |
| `vba/DateNumberOutput.bas` | デスクトップ XLAM 用の標準モジュール |
| `assets/` | 緑のカレンダーに「17」を描いた背景透過アイコン(`icon-16.png` / `icon-32.png` / `icon-64.png` / `icon-80.png`) |

### セットアップ

1. **GitHub Pages を有効化**: `Settings` → `Pages` → Source を `Deploy from a branch`、Branch を `main` / `(root)` にします。
2. 公開URL `https://mr2okama.github.io/excel-date-addin/` で `taskpane.html` が開けることを確認します。
3. 別のURLで公開する場合は、`manifest.xml` 内のURLをすべて置換してください。

### Excel への読み込み(サイドロード)

- **Excel on the web**: `挿入` → `アドイン` → `個人用アドイン` → `マニフェストのアップロード` で `manifest.xml` を選択
- **Windows デスクトップ**: Office.js 版のサイドロードには対応するカタログ設定や組織の配布ポリシーが必要です。上記の **XLAM 版ならカタログ登録を使わずに導入できます**。GitHub のファイルURLや GitHub Pages URL は Office アドインカタログではありません。

### 使い方

1. ホームタブの「番号出力」でタスクペインを開く
2. 数字を入力して「設定を保存」
3. 出力したいセルを選択して「出力」

### 注意

- 設定値は数字のみ受け付けます。
- 複数セルを選択している場合は、アクティブな1セルにのみ出力されます。
- `manifest.xml` の `<Id>` は固有のGUIDです。複製して使う場合は新しいGUIDに変更してください。
